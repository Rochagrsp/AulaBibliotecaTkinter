# 🐍 Cadastro de Clientes com Python & Tkinter

![Python](https://img.shields.io/badge/python-3670A0?style=for-the-badge&logo=python&logoColor=ffdd54)
![Tkinter](https://img.shields.io/badge/Tkinter-GUI-blue?style=for-the-badge)

Este repositório contém um exemplo prático de uma aplicação de interface gráfica (GUI) desenvolvida em Python utilizando a biblioteca padrão **Tkinter**. O projeto simula um sistema de cadastro de clientes com validação de campos e visualização de dados em abas.

## 🚀 Funcionalidades

- **Interface Tabulada:** Uso de `ttk.Notebook` para separar a área de cadastro da área de visualização.
- **Formulário de Cadastro:** Campos para Nome, Telefone, E-mail e Cidade.
- **Validação de Dados:** Alerta o usuário caso algum campo esteja vazio antes de processar o cadastro.
- **Visualização em Tabela:** Utilização de `ttk.Treeview` para listar os clientes cadastrados de forma organizada.
- **Feedback ao Usuário:** Janelas de mensagens (`messagebox`) para confirmação de sucesso ou aviso de erro.

## 🛠️ Tecnologias Utilizadas

- **Python 3.x**
- **Tkinter**: Biblioteca nativa para criação de interfaces gráficas.
- **TTK (Themed Tkinter)**: Widgets modernos como Notebook e Treeview.

## 📸 Demonstração Estrutural

A aplicação é dividida em:
1. **Aba Cadastro**: Onde o usuário insere os dados.
2. **Aba Clientes Cadastrados**: Onde os dados são exibidos após clicar no botão "Cadastrar".
